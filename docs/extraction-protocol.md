# Universal Extraction Protocol

For each source page capture:

- canonical source URL;
- title and description;
- content class;
- headings and hierarchy;
- explanatory text;
- ordered and unordered procedures;
- code and commands;
- tables;
- warnings and constraints when represented in page content;
- links for continued discovery.

Future semantic stages should distill raw pages into concepts, procedures, decision rules, limitations, troubleshooting patterns, examples and relationships while retaining source provenance.
